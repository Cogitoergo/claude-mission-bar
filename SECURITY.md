# Security

mission-bar reads figures the Claude Code session already holds (task list,
rate-limit windows, context fill, cache counts) and draws them. It makes no
network or model requests, runs no processes, and reads or writes no files.

To report a vulnerability, please use GitHub's
[private vulnerability reporting](https://github.com/Cogitoergo/claude-mission-bar/security/advisories/new)
rather than a public issue. Only the latest release is supported.
